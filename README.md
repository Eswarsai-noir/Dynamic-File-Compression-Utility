# Dynamic-File-Compression-Utility
A Huffman Coding based File Compression Utility built using Python, demonstrating Binary Trees, Min Heaps, Greedy Algorithms, and File Handling.

A Python-based Huffman Coding File Compression Utility that demonstrates core Data Structures & Algorithms concepts including Binary Trees, Min Heaps, Greedy Algorithms, and File Handling.

## Features

- File Compression
- File Decompression
- Frequency Analysis
- Huffman Tree Construction
- Compression Ratio Calculation
- Verification of Data Integrity

## Technologies

- Python
- Huffman Coding
- Binary Trees
- Min Heap
- Priority Queue
- File Handling
